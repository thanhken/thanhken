I'm **Ken** — a senior developer in Hanoi, building for the web and mobile since 2016.

I care about getting the problem *right* before getting it done, and I have a habit of turning the
annoying parts of my own workflow into tools other people end up using. Ten years across product
teams — from 2D games and iOS apps early on, to leading feature delivery, code review and release
planning at scale.

Off the clock I've been a **BBoy since 2010**. Never went pro, never stopped either.

| **2D games** | Math and interactive games for mobile and web. Where I started, still fun. |
